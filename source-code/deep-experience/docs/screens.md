## 旅行者向け画面（モバイルアプリ）

### 画面一覧

| # | 画面名 | 説明 |
|---|-------|------|
| T1 | **地図画面（ホーム）** | メインビュー。現在地周辺のツアーピンを表示 |
| T2 | **ツアーリスト画面** | ツアーをリスト形式で表示（地図と切替可能） |
| T3 | **ツアー詳細画面** | ツアーの詳細情報。予約ボタンあり |
| T4 | **予約入力画面** | 参加人数、連絡先、特記事項の入力 |
| T5 | **予約確認画面** | 入力内容の最終確認 |
| T6 | **予約完了画面** | リクエスト送信完了。ステータス表示 |
| T7 | **予約一覧画面** | 自分の予約一覧（メールアドレスで検索） |
| T8 | **予約詳細画面** | 予約のステータス、ガイド情報、集合場所 |

### 画面遷移

```mermaid
flowchart TD
    T1[T1: 地図画面\nホーム]
    T2[T2: ツアーリスト]
    T3[T3: ツアー詳細]
    T4[T4: 予約入力]
    T5[T5: 予約確認]
    T6[T6: 予約完了]
    T7[T7: 予約一覧]
    T8[T8: 予約詳細]

    T1 <-->|タブ切替| T2
    T1 -->|ピンタップ| T3
    T2 -->|ツアータップ| T3
    T3 -->|予約するボタン| T4
    T4 -->|確認ボタン| T5
    T5 -->|送信ボタン| T6
    T6 --> T8
    T1 -->|下部タブ| T7
    T7 -->|予約タップ| T8
```

### 画面詳細

#### T1: 地図画面（ホーム）

- 上部: 検索バー（エリア・カテゴリで検索）
- 中央: Google Maps（ツアーピンを表示）
- 下部: ボトムシート（直近のツアー一覧をスワイプで表示）
- フッター: 下部タブ（地図 / リスト / 予約）

#### T3: ツアー詳細画面

- ヘッダー: ツアー画像（カルーセル）
- ツアー名
- 日時（開始〜終了）
- 集合場所（名称 + ミニマップ）
- 残り枠 / 最大人数（グループの場合）
- 料金 / person
- カテゴリタグ
- 説明文
- CTAボタン「予約する」

#### T4: 予約入力画面

- ツアー情報サマリ（名称・日時）
- 参加人数（+/- ボタン）
- 連絡先（名前・メール・電話（任意））
- 特記事項（テキストエリア・任意）
- CTAボタン「確認画面へ」

## 旅行者とガイドのアプリ構成

### 方針: 1つのアプリ内で切替

Phase 0では旅行者アプリとガイドアプリを**1つのアプリ**にまとめる。

- デフォルトは旅行者モード（ログイン不要）
- ガイドとしてログインすると、ガイド用タブが表示される
- メリット: 開発コストが半分、ストア審査が1回で済む

```mermaid
flowchart LR
    A[アプリ起動] --> B{ログイン状態}
    B -->|未ログイン| C[旅行者モードのみ\n地図 / リスト / 予約]
    B -->|ガイドとしてログイン| D[旅行者タブ + ガイドタブ\n地図 / 予定 / 予約 / プロフィール]
```
