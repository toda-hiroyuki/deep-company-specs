# DeepExperience ユースケース一覧

## アクター定義

| アクター | 略称 | 説明 |
|----------|------|------|
| 旅行者 (Traveler) | T | 訪日観光客。アカウント不要、メールアドレスのみで予約・検索を行う |
| ガイド (Guide) | G | ツアーを実施するガイド。JWT認証でログイン |
| 管理者 (Admin) | A | 運営管理者。JWT認証でログイン。全リソースのCRUD権限を持つ |
| システム (System) | S | イベントトリガーによる自動処理 |

---

## 1. 認証

### 管理者

| ID | ユースケース |
|----|-------------|
| AUTH-A-01 | 管理者は、メールアドレスとパスワードでログインしJWTトークンを取得できる |
| AUTH-A-02 | 管理者は、管理画面からログアウトできる |

### ガイド

| ID | ユースケース |
|----|-------------|
| AUTH-G-01 | ガイドは、メールアドレスとパスワードでログインしJWTトークンを取得できる |

---

## 2. ツアー検索・閲覧

### 旅行者

| ID | ユースケース |
|----|-------------|
| TOUR-T-01 | 旅行者は、現在地の緯度・経度を指定して周辺のツアーを距離順に検索できる |
| TOUR-T-02 | 旅行者は、検索時にカテゴリ・ツアータイプ・日付範囲でフィルタできる |
| TOUR-T-03 | 旅行者は、ツアーの詳細情報（説明・画像・集合場所・所要時間・料金）を閲覧できる |
| TOUR-T-04 | 旅行者は、ツアーのスケジュール一覧（日時・残席数）を閲覧できる |
| TOUR-T-05 | 旅行者は、ツアーの空き状況を日付範囲指定で確認できる（料金情報含む） |
| TOUR-T-06 | 旅行者は、マップ上でツアーの集合場所をピンで確認できる（色分け: 緑=空き、橙=残少、灰=満席、青=プライベート） |
| TOUR-T-07 | 旅行者は、リスト形式でツアーを閲覧できる（サムネイル・料金・距離付き） |

---

## 3. 予約

### 旅行者

| ID | ユースケース |
|----|-------------|
| BOOK-T-01 | 旅行者は、スケジュールを選択して名前・メール・人数を入力し予約を作成できる |
| BOOK-T-02 | 旅行者は、メールアドレスで自分の予約一覧を検索・閲覧できる |
| BOOK-T-03 | 旅行者は、予約の詳細（ステータス・ツアー情報・ガイド情報・集合場所）を閲覧できる |
| BOOK-T-04 | 旅行者は、ツアー開始2時間前までに予約をキャンセルできる（PENDING/CONFIRMEDのみ） |

---

## 4. ガイドアサイン

### 管理者

| ID | ユースケース |
|----|-------------|
| ASGN-A-01 | 管理者は、PENDING予約に対してガイドをアサインできる |
| ASGN-A-02 | 管理者は、管理画面からアサインの承諾操作を代行できる |
| ASGN-A-03 | 管理者は、管理画面からアサインの辞退操作を代行できる（理由付き） |

### ガイド

| ID | ユースケース |
|----|-------------|
| ASGN-G-01 | ガイドは、自分宛のアサイン一覧を閲覧できる |
| ASGN-G-02 | ガイドは、アサインの詳細（予約情報・ツアー情報・旅行者情報）を閲覧できる |
| ASGN-G-03 | ガイドは、PENDINGアサインを承諾できる |
| ASGN-G-04 | ガイドは、PENDINGアサインを辞退できる（理由任意） |

---

## 5. ツアー実施

### ガイド

| ID | ユースケース |
|----|-------------|
| EXEC-G-01 | ガイドは、CONFIRMEDの予約に対してツアーを開始できる（ステータスをIN_PROGRESSに変更） |
| EXEC-G-02 | ガイドは、IN_PROGRESSの予約に対してツアーを完了できる（ステータスをCOMPLETEDに変更） |

## 6. ツアー管理

### 管理者

| ID | ユースケース |
|----|-------------|
| TMNG-A-01 | 管理者は、ツアーの一覧を閲覧できる |
| TMNG-A-02 | 管理者は、ツアーを新規作成できる（日英バイリンガル対応） |
| TMNG-A-03 | 管理者は、ツアーの基本情報を編集できる（タイトル・説明・集合場所・所要時間等） |
| TMNG-A-04 | 管理者は、ツアーの拡張情報を編集できる（ハイライト・含まれるもの・重要事項・アクセス情報等） |
| TMNG-A-05 | 管理者は、ツアーを論理削除できる（isActive=false） |

|----|-------------|

## 8. 可能枠ルール・CloseOut管理

### 管理者

| ID | ユースケース |
|----|-------------|
| RULE-A-01 | 管理者は、CapacityRule（可能枠ルール）の一覧を閲覧できる |
| RULE-A-02 | 管理者は、CapacityRuleを作成できる（WEEKLY/RANGE/SINGLE/YEARLYの4タイプ、曜日・開始時刻・定員・優先度を指定） |

| RULE-A-04 | 管理者は、CloseOut（除外日時）の一覧を閲覧できる |
| RULE-A-05 | 管理者は、CloseOutを作成できる（全日ブロックまたは特定時間帯ブロック、理由任意） |
| RULE-A-06 | 管理者は、CloseOutを削除できる |

## 17. 自動処理

### システム

| ID | ユースケース |
|----|-------------|
| SYS-S-01 | システムは、予約作成時にスケジュールの残席数を自動的に減少させる |
| SYS-S-02 | システムは、残席が0になった場合にスケジュールステータスを自動的にFULLに変更する |
| SYS-S-03 | システムは、予約キャンセル時にスケジュールの残席数を自動的に復元しステータスをOPENに変更する |
| SYS-S-04 | システムは、ガイドがアサインを承諾した時に予約ステータスを自動的にCONFIRMEDに変更する |
| SYS-S-05 | システムは、ガイドがアサインを承諾した時に旅行者にBOOKING_CONFIRMED通知を自動送信する |
| SYS-S-06 | システムは、ガイドがアサインを辞退した時に旅行者にGUIDE_DECLINED通知を自動送信する |
| SYS-S-07 | システムは、画像アップロード時にサムネイル（400x300, JPEG）を自動生成する |
